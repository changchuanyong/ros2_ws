## 4. 相邻双音结果（T-0060，48→50）

### 4.1 规则控制验收

配置 `first_press_delay=0.26 / press_delay=0.22 / prep_gap=8mm`，复用亚栅格释放。

| 音符 | 起音 | 释放 | 时长 | 峰值力 | ±30ms |
| --- | --- | --- | --- | --- | --- |
| key48 | −6ms | +16ms | +22ms | 1.95N | 通过 |
| key50 | +10ms | −3ms | −13ms | 2.18N | 通过 |

碰撞 0 / 限位 0 / 早触 0 / 误触 0，complete_pass=True。

### 4.2 四组消融（冻结 mk20k_v2，配对 seed=101，obs=1228 兼容）

| 组 | 控制器 / 策略 | F1 | P / R | key48 起音 | key50 起音 | 碰撞 | 通过 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| a | 原 DroQ + 原控制器 | 0.608 | 1.00 / 0.437 | +63ms | +266ms | 0 | 否 |
| b | 纯规则 PrepositionTask | 0.971 | 0.964 / 0.978 | −6ms | +10ms | 0 | 是 |
| c | 冻结 DroQ + PrepositionTask | 0.758 | 0.959 / 0.627 | +161ms | +60ms | 0 | 否 |
| d | PrepositionTask + 零动作 | 0.000 | 0 / 0 | 漏 | 漏 | 0 | 否 |

结果要点：

- d 组零动作 F1=0、峰值力 0：预定位本身不按键，压键由策略发出。
- a→b 后续键起音 +266→+10ms：渡越修复来自规则预定位。
- c 组首键 +161ms：冻结策略时序不迁移预定位接口（观测维度兼容）。
- d 组零动作用 canonical −1（qdes 0）；canonical 0 会映射成半压深 0.032。

## 5. 失败与限制结果

| 实验 | 结果 |
| --- | --- |
| 50ms 开环位置目标（T-0052） | 44 候选全未通过，峰值力 21–30N，全碰撞 |
| 50ms 力反馈/阻抗（T-0053） | 23 候选无干净：6 不激活、17 激活但 link3 碰撞（10–22N） |
| 隔键/远距渡越（T-0060） | 碰撞 91–161 帧 |
| 亚栅格键间提前释放 | 任何提前量 >0（含 4ms）→ 51–66 帧 link3 碰撞，峰值力 9–10N |
| 亚栅格末键释放 | −3ms（安全，直抬回家） |
| 冻结策略迁移预定位接口 | 首键 +161ms，不通过 |

link3 机理：right_collision_21 比指腹低 0.233mm；软指腹下沉 ~1.2mm 必撞键缘，匹配 solref 0.004 后指尖不下沉→零 link3。键间提前释放新增抬指跳变，键回弹撞 link3。
