# 静态参考演奏姿态（RM75 双臂 + L20）

本页固定一套已经确认的双臂静态姿态，作为后续弹琴规划的 **home/reference posture**。
它只定义手臂的整体形态和初始关节角；不是把整首曲子的所有关节角冻结。

## 1. 使用的场景

- 场景文件：`config/piano_scene_static5.yaml`
- 工作台：`y = -0.58 m`
- 左/右机械臂底座：`x = -0.27 / +0.27 m`，`y = -0.28 m`，`z = 0.76 m`
- 钢琴：`y = 0.15 m`，`z = 0.74 m`
- 钢琴尺寸、88 键几何、键高、键深和碰撞体未改。

## 3. 以后弹琴必须遵守的规则

1. **起始和回位**
   每个乐句或整曲开始时，先到本页的参考关节角附近；结束时回到该姿态附近。
   规划器应以这组关节角作为 IK 初值或姿态参考，而不是从旧的“低肘折叠”姿态起算。

2. **保持形态**
   允许手臂为不同音区移动，但必须保持以下形态：
   - 大臂从桌面抬起，不趴在桌面附近；
   - 肘部接近肩高，不能落回桌面高度；
   - 前臂从高位向前下方伸向键盘；
   - 手掌朝下，手指指向琴键。

3. **弹奏前抬手**
   本页姿态是指尖贴在键面上的静态展示姿态。真正演奏时应先把手指抬起约
   `0.03 m`（或把 `hand_curl` 降到约 0.25）形成 `PLAY_READY`，再下键；
   不要在键面上横向拖动手指。

4. **不要冻结整曲**
   本页固定姿势只覆盖双手附近的局部琴键（左手 G3、右手 C5 一带）。
   88 键演奏需要手臂在保持上述形态的前提下移动；
   不能把这 14 个关节角当成整曲固定解。

5. **验收不放松**
   关节限位、机械臂/钢琴/桌面碰撞、目标键接触、非目标键和键行程仍按现有严格检查；
   不修改阈值、乐谱、指法或钢琴尺寸。

## 4. 覆盖与限制

- 当前布局的几何可达性预筛为 **88/88**（左右各 66 键，中音区重叠约 18 键）；
  实际 IK + 动态按键验收需以单独报告为准。
- 手放到琴键上后，肘部只能保持在肩部附近（约 -0.6 ~ -1.3 cm 相对肩高），
  比“手悬在键面上方”时更低。若要同时保持更高肘部和键面接触，需要把底座
  向钢琴方向前移或把钢琴拉近；当前布局优先满足桌子后退和手贴键。
